🧩 I. CÁC KIỂU “INT” CƠ BẢN CHUẨN NGÔN NGỮ

Kiểu dữ liệu Kích thước (thường) Phạm vi giá trị Ghi chú
int 4 byte (phổ biến) -2,147,483,648 → 2,147,483,647 Kiểu nguyên mặc định trên nhiều nền tảng (32-bit)

long int 4 byte hoặc 8 byte (tùy nền tảng) Nếu 4 byte: giống int. Nếu 8 byte: -9,223,372,036,854,775,808 → 9,223,372,036,854,775,807 Kích thước phụ thuộc ABI (Windows: thường 4; Linux x86_64: thường 8)
long long int 8 byte -9,223,372,036,854,775,808 → 9,223,372,036,854,775,807 Dùng khi cần vùng số rất lớn (C++11 đảm bảo ít nhất 64-bit)

🔍 Ví dụ: In kích thước & phạm vi (dùng <limits>)

#include <iostream>
#include <limits>
using namespace std;

int main() {
  cout << "sizeof(int) = " << sizeof(int) << " bytes\n";
  cout << "int range: " << numeric_limits<int>::min() << " ... " << numeric_limits<int>::max() << endl;
  cout << "unsigned long long max = " << numeric_limits<unsigned long long>::max() << endl;
  return 0;
}

Kết quả (trên hệ phổ biến 64-bit Linux / Windows):

sizeof(int) = 4 bytes
int range: -2147483648 ... 2147483647
unsigned long long max = 18446744073709551615

🧱 II. BIẾN THỂ “KHÓA / CẤM SỬA” – const, constexpr

Từ khóa Ý nghĩa Ví dụ Ghi chú
const Biến hằng, không thể thay đổi sau khi gán const int x = 10; Phổ biến; có thể là runtime-constant nếu được gán từ biến
constexpr Hằng được tính tại thời điểm biên dịch (compile-time) constexpr int y = 5 * 2; Bắt buộc là constant expression → dùng cho kích thước mảng, template
static const Hằng số có phạm vi file/module static const int MAX = 100; Thường dùng trong header/source để giới hạn phạm vi

🔍 Ví dụ minh họa différence const vs constexpr

#include <iostream>
#include <array>
using namespace std;

const int A = 3;            // có thể là runtime constant
constexpr int B = 4 * 2;    // compile-time constant

int main() {
  int arr1[A];              // (trong một số compiler cũ có thể báo lỗi) 
  array<int,B> arr2;   // B chắc chắn là compile-time → hợp lệ
  cout << "A = " << A << ", B = " << B << endl;
  return 0;
}

Kết quả: A = 3, B = 8

⚙️ III. BIẾN THỂ “LƯU TRỮ / VỊ TRÍ” (Storage Class Specifiers)

Từ khóa Tác dụng Phạm vi ảnh hưởng
static Giữ giá trị giữa các lần gọi hàm (lifetime toàn bộ chương trình) Biến cục bộ hoặc toàn cục
register Gợi ý lưu trong register CPU (không còn cần thiết hiện nay) Biến cục bộ
extern Khai báo biến ở nơi khác (liên kết giữa các file .cpp) Biến toàn cục (nhiều file)
thread_local Mỗi luồng có bản sao riêng của biến Lập trình đa luồng

🔍 Ví dụ cho static và thread_local

#include <iostream>
using namespace std;

void inc() {
  static int counter = 0; // giữ giá trị giữa các lần gọi
  cout << "counter = " << ++counter << endl;
}

int main() {
  inc(); // counter = 1
  inc(); // counter = 2
  inc(); // counter = 3
  return 0;
}

Kết quả:

counter = 1
counter = 2
counter = 3

🔄 IV. BIẾN THỂ “TÍNH CHẤT BIÊN DỊCH / BỘ NHỚ”

Từ khóa Ý nghĩa Ghi chú / Ứng dụng
volatile Báo cho compiler: biến có thể thay đổi ngoài chương trình Dùng trong lập trình hệ thống, đọc giá trị phần cứng, ngăn compiler tối ưu hoá loại bỏ các lần đọc
mutable Cho phép thay đổi thành viên trong class ngay cả khi object là const Dùng cho cache, lazy-evaluation trong phương thức const

🔍 Ví dụ mutable (thay đổi trong phương thức const)

#include <iostream>
using namespace std;

struct Item {
  mutable int cache = 0;
  int get() const {
    cache++; // hợp lệ vì cache là mutable
    return cache;
  }
};

int main() {
  const Item it;
  cout << it.get() << endl; // 1
  cout << it.get() << endl; // 2
  return 0;
}

Kết quả: 1 và 2

🧮 V. CÁC KIỂU “INT ĐẶC BIỆT” TRONG <cstdint> (C++11+)

Thư viện <cstdint> định nghĩa các kiểu có **kích thước chính xác** — rất hữu ích khi lập trình hệ thống, mạng, nhúng.

Kiểu Kích thước Ghi chú
int8_t / uint8_t1 byteTương đương signed/unsigned char
int16_t / uint16_t2 byteTương đương short
int32_t / uint32_t4 byteTương đương int (trên nhiều hệ)
int64_t / uint64_t8 byteTương đương long long
intptr_t / uintptr_tTùy nền tảngĐủ lớn để chứa pointer (dùng khi cần chuyển đổi giữa con trỏ và số)

🔍 Ví dụ dùng <cstdint> và <limits>

#include <iostream>
#include <cstdint>
#include <limits>
using namespace std;

int main() {
  cout << "int32_t size = " << sizeof(int32_t) << " bytes, range: "
       << numeric_limits<int32_t>::min() << " ... " << numeric_limits<int32_t>::max() << endl;
  cout << "uint64_t max = " << numeric_limits<uint64_t>::max() << endl;
  return 0;
}

Kết quả:

int32_t size = 4 bytes, range: -2147483648 ... 2147483647
uint64_t max = 18446744073709551615

4️⃣ Cấu trúc điều kiện

👉 Dùng để rẽ nhánh chương trình dựa trên điều kiện đúng/sai.

Ví dụ if - else: 
int x;
cin >> x;
if (x > 0) 
  cout << "Số dương";
else if (x == 0)
  cout << "Số 0";
else 
  cout << "Số âm";
Ví dụ switch - case: 
int n;
cin >> n;
switch (n) {
  case 1: cout << "Một"; break;
  case 2: cout << "Hai"; break;
  case 3: cout << "Ba"; break;
  default: cout << "Khác";
}
STT Tên cấu trúc Cú pháp Chức năng Chú thích chi tiết • Ví dụ (1 lệnh) • Kết quả
1️⃣ if if (điều_kiện) { ... } Thực hiện khi điều kiện đúng Chú thích: Cú pháp cơ bản; dùng cho một nhánh.
Ví dụ: if (x > 0) cout << "Pos";
Kết quả: In Pos nếu x > 0.
2️⃣ if - else if (...) { ... } else { ... } Hai nhánh lựa chọn Chú thích: Nếu điều kiện sai thì thực thi nhánh else.
Ví dụ: if (x%2==0) cout << "Even"; else cout << "Odd";
Kết quả: In Even hoặc Odd tuỳ x.
3️⃣ if - else if - else if (...) ... else if (...) ... else ... Nhiều điều kiện nối tiếp Chú thích: Kiểm tra tuần tự; dừng ở nhánh đầu đúng.
Ví dụ: if(n==1) cout << "1"; else if(n==2) cout << "2"; else cout << "Other";
Kết quả: In giá trị tương ứng hoặc Other.
4️⃣ Toán tử 3 ngôi (?:) (cond) ? expr_true : expr_false; Cấu trúc điều kiện rút gọn Chú thích: Dùng trong biểu thức, tiện cho gán nhanh.
Ví dụ: int m = (a > b) ? a : b;
Kết quả: m là giá trị lớn hơn.
5️⃣ switch - case switch(expr) { case x: ...; break; default: ... } Rẽ nhánh theo giá trị nguyên Chú thích: Thường dùng với int/enum; nhớ break để tránh fall-through (trừ khi muốn).
Ví dụ: switch(n){case 1: cout << "1"; break; default: cout << "?";}
Kết quả: In 1 khi n==1, else ?.
6️⃣ Lồng điều kiện if (...) { if (...) {...} } Điều kiện trong điều kiện Chú thích: Dùng khi muốn kiểm tra nhiều cấp độ điều kiện.
Ví dụ: if (a>0) if (b>0) cout << "both";
Kết quả: In both khi cả a và b dương.
7️⃣ return có điều kiện if (cond) return x; else return y; Dừng hàm theo điều kiện Chú thích: Thường dùng để thoát sớm khi điều kiện không hợp lệ.
Ví dụ: if (x < 0) return -1; else return 0;
Kết quả: Hàm trả -1 nếu x<0, else 0.
8️⃣ goto + label if(...) goto label; Nhảy đến vị trí chỉ định (hiếm dùng) Chú thích: Cổ điển, dễ gây khó đọc/bug, tránh dùng nếu không cần thiết.
Ví dụ: if(err) goto end; /*...*/ end: cout << "done";
Kết quả: Nếu err true → nhảy tới nhãn end.
9️⃣ Cấu trúc với toán tử logic if (a > 0 && b > 0) Kết hợp nhiều điều kiện Chú thích: Hỗ trợ && (AND), || (OR). Lưu ý short-circuit.
Ví dụ: if (a > 0 && b > 0) cout << "ok";
Kết quả: In ok khi cả hai đúng.
🔟 Static if (C++20) if constexpr (điều_kiện_compile) { ... } Kiểm tra tại thời điểm biên dịch Chú thích: Thực thi hoặc bỏ đoạn mã ở compile-time; hữu ích trong generic programming.
Ví dụ: if constexpr (sizeof(int)==4) cout << "32-bit int";
Kết quả: Biểu thức compile-time quyết định việc biên dịch nhánh nào.
1️⃣1️⃣ Short-circuit eval a && b và a || b Rút ngắn đánh giá điều kiện Chú thích: Với &&, nếu trái false → phải không được gọi; với ||, nếu trái true → phải không được gọi.
Ví dụ: if (a && check()) cout << "ok";
Kết quả: check() chỉ được gọi nếu a true.
1️⃣2️⃣ Pattern / init in if (C++17/23) if (init-statement; condition) { ... } Khai báo & kiểm tra trong cùng một if (structured binding / pattern) Chú thích: C++17 cho phép if (init; cond); kết hợp structured binding rất tiện. C++23 mở rộng pattern matching hơn.
Ví dụ: if (auto [x,y] = val; x > 0) cout << x;
Kết quả: x được in khi điều kiện đúng; x,y chỉ tồn tại trong if.

6️⃣ Hàm (Function)

👉 Hàm giúp chia chương trình thành các khối nhỏ, dễ quản lý và tái sử dụng.

Ví dụ hàm tính tổng: 
int tong(int a, int b) {
  return a + b;
}

int main() {
  cout << "3 + 4 = " << tong(3,4);
  return 0;
}
// Kết quả: 3 + 4 = 7

🧩 TOÀN BỘ LỆNH & CÚ PHÁP VỀ HÀM (FUNCTION) TRONG C++

🧠 I. Khái niệm cơ bản

Hàm (function) là một khối lệnh có tên, dùng để thực hiện một nhiệm vụ cụ thể, có thể truyền dữ liệu vào (tham số) và trả kết quả ra (return).

👉 Giúp:
– Chia nhỏ chương trình → dễ quản lý, dễ đọc
– Dễ tái sử dụng
– Giảm lặp lại code

🧩 II. Cấu trúc của một hàm trong C++

🧱 Cú pháp tổng quát:

kiểu_trả_về tên_hàm(danh_sách_tham_số) {
    // khối lệnh
    return giá_trị; // nếu có
}

💡 Ví dụ:

#include <iostream>
using namespace std;

int cong(int a, int b) {
    return a + b;
}

int main() {
    int tong = cong(3, 5);
    cout << "Tổng = " << tong;
    return 0;
}

📝 Giải thích:

  • int → kiểu dữ liệu trả về
  • cong → tên hàm
  • (int a, int b) → danh sách tham số
  • return a + b; → trả về kết quả

int giaiThua(int n) {

9️⃣ Tạm dừng chương trình (Sleep / Delay)

Trong C++, nếu bạn muốn chương trình dừng lại một khoảng thời gian rồi mới in tiếp — ta dùng hàm Sleep hoặc sleep tùy hệ điều hành.

🪟 Trên Windows (Dev C++, Code::Blocks…)

Dùng hàm Sleep(milliseconds) trong thư viện <windows.h>. Đơn vị là mili giây (1000 ms = 1 giây).

#include <iostream>
#include <windows.h> // để dùng Sleep
using namespace std;

int main() {
    cout << "Chuan bi...\n";
    Sleep(1000);  // đợi 1 giây

    cout << 3 << endl;
    Sleep(1000);

    cout << 2 << endl;
    Sleep(1000);

    cout << 1 << endl;
    Sleep(1000);

    cout << "Bat dau!" << endl;
    return 0;
}

🐧 Trên Linux / Mac

Dùng hàm sleep(seconds) trong thư viện <unistd.h>. Đơn vị là giây.

#include <iostream>
#include <unistd.h> // để dùng sleep
using namespace std;

int main() {
    cout << "Chuan bi...\n";
    sleep(1);  // đợi 1 giây

    cout << 3 << endl;
    sleep(1);

    cout << 2 << endl;
    sleep(1);

    cout << 1 << endl;
    sleep(1);

    cout << "Bat dau!" << endl;
    return 0;
}

🌍 Đa nền tảng (Windows, Linux, Mac)

Đây là cách hiện đại nhất, dùng thư viện chuẩn <chrono> và <thread> — chạy được trên mọi hệ điều hành hỗ trợ C++11 trở lên.

#include <iostream>
#include <chrono>   // để dùng chrono::milliseconds
#include <thread>   // để dùng this_thread::sleep_for
using namespace std;

int main() {
    cout << "Chuan bi...\n";
    this_thread::sleep_for(chrono::milliseconds(500)); // đợi 0.5 giây

    cout << 3 << endl;
    this_thread::sleep_for(chrono::milliseconds(500));

    cout << 2 << endl;
    this_thread::sleep_for(chrono::milliseconds(500));

    cout << 1 << endl;
    this_thread::sleep_for(chrono::milliseconds(500));

    cout << "Bat dau!" << endl;
    return 0;
}

📘 Ghi chú:

Nền tảng Dừng theo giây Dừng theo mili giây
🪟 Windows Sleep(3000); → 3 giây Sleep(500); → 0.5 giây
🐧 Linux / Mac sleep(3); → 3 giây usleep(500000); → 0.5 giây
🌍 Đa nền tảng (C++11+) this_thread::sleep_for(chrono::seconds(3)); this_thread::sleep_for(chrono::milliseconds(500));

Khuyến nghị: Dùng cách đa nền tảng (C++11 trở lên) để code hiện đại và tương thích cao.

📘 Thư viện <iomanip> — Bảng lệnh (một lệnh • một ví dụ • kết quả)

(đặc biệt hữu ích khi làm bảng, in số thực, căn lề, định dạng tiền tệ, v.v.)

Lệnh Công dụng Chú thích chi tiết Ví dụ (dòng lệnh) Kết quả (hiển thị)
setprecision(n) Đặt số chữ số có nghĩa (mặc định) hoặc chữ sau dấu phẩy (khi dùng fixed). Nếu không có fixed, setprecision điều khiển *significant digits*; với fixed thì điều khiển số chữ sau dấu thập phân. cout << setprecision(3) << 12.3456; 12.3
fixed In số thực ở dạng cố định — giữ đúng số chữ sau dấu phẩy theo setprecision. Thường dùng để hiển thị số thập phân cố định (ví dụ tiền tệ, phần trăm), kết hợp với setprecision. cout << fixed << setprecision(2) << 3.14159; 3.14
scientific In số thực ở dạng khoa học (dạng m × 10^e, có 'e'). Hoạt động cùng setprecision để điều khiển số chữ số hiển thị (mặc định 6 chữ số nghĩa). cout << scientific << setprecision(6) << 123.456; 1.234560e+02
showpoint Luôn hiển thị dấu thập phân và các chữ số sau (theo precision) ngay cả nếu là .0. Giúp hiển thị đồng nhất định dạng số (ví dụ 5.00000 thay vì 5). cout << setprecision(5) << showpoint << 5.0; 5.0000
noshowpoint Tắt hiển thị phần thập phân khi không cần (mặc định). Sử dụng khi muốn hiện dạng ngắn gọn cho số nguyên/float .0. cout << noshowpoint << 5.0; 5
showpos Hiển thị dấu + trước các số dương. Tiện khi cần làm nổi bật số dương (ví dụ báo cáo thay đổi ±). cout << showpos << 42; +42
noshowpos Tắt hiển thị dấu + (mặc định). Trở về trạng thái không in dấu cộng trước số dương. cout << noshowpos << 42; 42
dec In số ở hệ thập phân (decimal) — chế độ mặc định. Dùng khi trước đó bạn đã đổi sang hex hoặc oct và muốn quay về decimal. cout << dec << 255; 255
hex In số ở hệ 16 (hexadecimal). Chữ hex thường in bằng chữ thường trừ khi dùng uppercase. cout << hex << 255; ff
oct In số ở hệ 8 (octal). Ít dùng nhưng hữu ích khi thao tác với chế độ cấp phát file/perm. cout << oct << 255; 377
uppercase In chữ hex và ký hiệu khoa học ('E') ở dạng chữ hoa. Ảnh hưởng tới hex letters và phần exponent trong scientific. cout << uppercase << hex << 255; FF
nouppercase Quay về in thường (mặc định). Trở lại hành vi mặc định của thư viện IO. cout << nouppercase << hex << 255; ff
setw(n) Đặt độ rộng tối thiểu của trường in ra (padding nếu nhỏ hơn). Không phải manipulator vĩnh viễn — chỉ áp dụng cho lần in tiếp theo. cout << setw(5) << 42; " 42"
setfill(ch) Đặt ký tự để lấp đầy khoảng trống khi dùng setw. Ảnh hưởng cho các lần in tiếp theo cho tới khi thay đổi lại. cout << setfill('*') << setw(5) << 42; "***42"
left Căn trái nội dung trong trường có độ rộng (setw). Thường kết hợp với setw và setfill. cout << left << setw(5) << 42; "42 "
right Căn phải nội dung (mặc định thường là right). Phù hợp in số, căn chữ sang phải. cout << right << setw(5) << 42; " 42"
internal Giữ dấu (sign) ở trái, căn phải phần số; padding nằm giữa dấu và phần số. Hữu ích khi in số âm/với dấu và cần giữ dấu ở vị trí cố định. cout << internal << setw(6) << -42; "- 42"
boolalpha In giá trị boolean dưới dạng true/false thay vì 1/0. Thay đổi trạng thái luồng cho đến khi dùng noboolalpha. cout << boolalpha << true; true
noboolalpha Quay về in 1/0 (mặc định). Trở về trạng thái mặc định in boolean là 1/0. cout << noboolalpha << true; 1
ws Bỏ qua tất cả ký tự trắng (space, tab, newline) trước khi đọc tiếp (dùng với >> hoặc getline). Rất hữu ích khi chuyển từ >> sang getline để loại bỏ newline/space thừa. getline(cin >> ws, name); Đọc nguyên dòng, bỏ khoảng trắng đầu

🧠 Ghi nhớ nhanh

  • fixed + setprecision(n) để kiểm soát chữ sau dấu phẩy.
  • Dùng setw + setfill + left/right/internal để căn lề & padding.
  • hex/dec/oct chuyển hệ đếm; uppercase ảnh hưởng chữ hex & exponent.
  • boolalpha giúp in true/false thân thiện; ws dùng khi đọc dòng sau >>.
